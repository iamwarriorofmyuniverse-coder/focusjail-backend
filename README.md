# 🔒 FocusJail - Radical AI Accountability System

An uncompromising productivity & anti-procrastination application that holds you hostage to your daily commitments.

## 🚀 Features
- **3 Accountability Styles**: Brutal Warden 🔥, Firm Commander ⚔️, Empathetic Mentor 🌱.
- **Dynamic Inmate Ranks**: Level up from *Inmate #0042* to *Liberated Sovereign* via unbroken daily streaks.
- **Interactive Daily Checklist**: Check off commitments in real time throughout your day.
- **Deep Focus Lockdown Cell**: Built-in 25-minute Deep Work / Pomodoro timer with visual lockdown bars.
- **Web Audio FX Synthesizer**: Immersive clicks, locks, and alarms without any external audio asset dependencies.
- **7-Day Accountability Heat Strip**: Visual history of your triumphs and failures.
- **Groq Llama 3.3 70B & 8B Instant Integration**: Instantaneous, punchy AI verdicts.

## 📁 File Structure
- `index.html` - Enhanced single-page frontend application
- `server.js` - Express backend proxying Groq API with model fallbacks & safety checks
- `package.json` - Node dependencies

## 🛠️ Local Development
```bash
# Install dependencies
npm install

# Start backend server
GROQ_KEY=your_groq_api_key npm start
```
Then open `index.html` in your browser.
